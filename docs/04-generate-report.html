Generating a Report

An introduction to generating reports with Quarto

The main objective of this section is to learn how to use Quarto Documents to create an HTML report that contains data visualizations and statistical analyses.

Prepare

Before starting this class:

What is Quarto?

In the previous section, you learned how to do a basic transformation of data, visualize the data, and perform a simple statistical analysis. You did this using R scripts. R scripts are great for processing data and generating output files, but they are not ideal for creating reports that contain figures, tables, and statistical analyses. If I were to ask you now, what was that correlation between the two variables you calculated in the previous section, you would have to go back and run each line of code in the R script to find out.

Unlike R scripts, Quarto documents allow you to generate a report document that contains the figures, tables, and statistical analyses. You can then go back and view this report at any time to find out what the correlation was - without having to run any code and without having to open Positron or R. The report will open in your default web browser. This report can also be shared with others and they can view the figures, tables, and statistical analyses in a web browser without having to run any code.

In this section, we will take the code you wrote in the previous section and use it to create a report document that contains the figures, tables, and statistical analyses.

Tip

You may want to watch this video for a brief intro to Quarto.

There are three types of content that form the structure of a Quarto document.

  • A YAML header

  • Markdown formatted text

  • R code chunks

YAML Header

The YAML header contains metadata about how the document should be rendered and the output format. It is located at the very top of the document and is surrounded by lines of three dashes.

---
title: "Title of document"
format: html
---

There are various metadata options you can specify, such as if you want to include a table of contents. To learn about a few of them see the documentation here.

For this section, we will keep it simple and just specify the title of the document and the output format. You can add more options later. An HTML format is a good choice for generating a report document because it can be easily shared and viewed in a web browser.

Note

  • Here is a list of all the HTML format YAML options

  • Here is a user guide on creating HTML output

In the Quarto document you created for this section, add the following YAML header at the top of the document:

---
title: "An introduction to generating reports with Quarto"
format: html
---

Markdown Text

Markdown text is just as if you were writing content in Microsoft Word or Google Docs. You can write up paragraphs of text, create bullet or numbered lists, embed images or web links, create tables, and more. The text is formatted using a language known as Markdown. Markdown is a convenient and flexible way to format text. When a Markdown document is rendered into some output (such as HTML or PDF), the text will be formatted as specified by Markdown syntax. There are a lot of guides on how to use Markdown syntax. I will not cover this so you should check them out on your own. Here is one I reference often: Markdown Cheatsheet

You can also create headers in Markdown. Headers are used to organize the content of a document into sections and subsections. Headers are created by using hash symbols (#) followed by a space and the title of the section. The number of hash symbols used indicates the level of the header. For example, a level 1 header is created with one hash symbol, a level 2 header is created with two hash symbols, and so on.

Add some markdown text below the YAML header in your open Quarto document. Markdown text can be added anywhere in the document, without surrounding it with any special characters. For example, you can add the following text just below the YAML header:

## Description

In this document we will:

1. Load the penguins dataset.
2. Calculate the mean body mass and flipper length of each penguin species.
3. Create a scatter plot of body mass vs flipper length for each penguin species.
4. Calculate the correlation between body mass and flipper length.

R Code Chunks

R code chunks are used to include R code in a Quarto document. R code chunks are enclosed with three backticks and the letter r (or {r} for Quarto). The R code in the chunk will be executed when the document is rendered, and the results will be included in the output document. You can also specify options for the R code chunk, such as whether to show the code or just the results, whether to evaluate the code or not, and more.

Note
  • Here is a list of all the R code chunk options
  • Here is a user guide on R code chunks

Add a first R code chunk to your Quarto document directly below the markdown text.

  1. First, insert an R code chunk using the shortcut:

Mac: ⌘ ⌥ i (command + alt/opt + i) or ⌘ shift i (command + shift + i)

Windows: ⌃ ⌥ i (ctrl + alt + i)

  1. Then, add the following code to the R code chunk:
library(palmerpenguins)

head(penguins)

Executing R Code Chunks

Often times, when you are writing a Quarto document, you will want to run the R code chunks to see the results of the code. You can do this by executing the R code chunks.

To run chunks of R code you can click on the “Run Cell” button on the top left of the R code chunk. Alternatively, you can run each line of code one at a time by placing your cursor on the line of code and use the keyboard shortcuts:

Mac: ⌘ enter (command + enter) Windows: Ctrl + Enter (ctrl + enter)

Next Steps

Now let’s go through and add headers and the rest of the code you wrote in the previous section to the Quarto document. You may also want to add some markdown text to describe what you are doing in each section of the document.

First, just go ahead and delete the R code chunk we just created and we will add the R code chunks one section at a time.

Load Packages

Directly under the markdown text, add a level 2 header for the first section titled “Load Packages”. Under the header, and an R code chunk and add the following code to load the packages we will be using in this document:

# load packages
library(palmerpenguins)
library(dplyr)
library(ggplot2)
Note

The code we will add for each section can is directly copied from the previous sectioin.

Additionally, to clean up the document and remove unwanted messages and warning, we will add the following options to the R code chunk:

#| messages: false
#| warning: false

Add these two lines of code directly below the three backticks and the letter r in the R code chunk. The R code chunk should look like this:

#| messages: false
#| warning: false

# load packages
library(palmerpenguins)
library(dplyr)
library(ggplot2)

Import Data

Next, add a level 2 header for the next section titled “Import Data”. Under the header, add an R code chunk and add the following code to import the penguins dataset:

# import data
data_import <- penguins

Analysis

Next, add a level 2 header for the next section titled “Analysis”. Under the header add in separate R code chunks for transforming the data, creating the scatter plot, and calculating the correlation. You can feel free to create additional level 3 headers and markdown text to describe what you are doing in each section of the analysis.

Transform data:

# transform data
data_plot <- data_import |>
  mutate(.by = species,
         flipper_length_mm.mean = mean(flipper_length_mm, na.rm = TRUE),
         body_mass_g.mean = mean(body_mass_g, na.rm = TRUE))

Create Scatter Plot:

# visualize data
ggplot(data_plot, aes(x = flipper_length_mm, y = body_mass_g,
                      color = species, shape = species)) +
  geom_point(size = 1, alpha = .5) +
  geom_point(aes(x = flipper_length_mm.mean, y = body_mass_g.mean, 
                 color = species), size = 3) +
  theme_classic()

Calculate Correlation:

# statistical analysis
cor.test(data_import$body_mass_g, data_import$flipper_length_mm)
